- Goal clarified: endpoint must use pure learned value-head leaves replacing rollout. Rollout/value blending is diagnostic only, not an acceptable endpoint.
- Current best pure learned-leaf result remains far below target: 50k teacher corpus did not improve gate strength despite better validation q_loss.
- 50k teacher corpus (`runs/qhead-v32-50k-teacher-corpus/selfplay-50k.jsonl`): 53,164 rows, 4,000 unique seeds, 28,848 player / 24,316 opponent rows, 22/22 deck pairs, zero bad rows. It was generated with eight parallel chunk processes before the Rust selfplay worker-pool fix.

- 50k diagnostic: q predictions correlate with targets but are MCTS-weak. Target-argmax accuracy **0.467**, predicted argmax in target top-2 **0.831**, scalar correlations mean/top2/top3/max **0.793/0.783/0.786/0.750**. - Random-bot floor (`runs/random-bot-baseline/`) added `sim-eval-gate --selection random`, a true uniform legal-action modeled-side baseline. Fixed n=1000/side random reached wr **0.3635**, wl **0.3427**; uniform-deck n=1000/side random reached wr **0.4045**, wl **0.3832**. Current pure value-head failures are weak but above random, not catastrophic random-level play.
- High-sim label-stability probe (`runs/qhead-v32-highsim-label-stability-probe/`) re-ran the first 20 seeds/side from the 50k corpus at 800 sims. It produced 40 games / 280 rows. Whole-game trajectories diverged quickly: 137 `(seed, sideId, step)` matches but only 47 exact observation matches. On exact matches, 200-sim labels were already stable: Q-pair corr **0.957**, target argmax agreement **0.787**, selected-action agreement **0.915**, mean abs Q delta **0.096**. Verdict: do not brute-force whole games; high-sim work needs a state-level relabeler focused on hard/leaf-distribution states.
- Leaf-state tooling is now available: `sim-mcts-selfplay --record-rollout-leaf-rows --rollout-leaf-rows-per-decision N` emits internal rollout-leaf states as value-target rows with `rootValue = rollout label`, and `--workers` now runs games concurrently in-process. Smoke `runs/leaf-state-value-target-smoke/` emitted 108 valid leaf rows and `ValueTargetDataset(..., state_dim=110, uses_uma_slot_tokens=True)` loaded all 108. Worker determinism smoke `runs/selfplay-worker-determinism-smoke/` confirmed workers 1 vs 2 produce byte-identical JSONL on a fixed 6-game run.

Verdict: exact-state higher-K relabel reduces target saturation but does not make the current frozen-trunk scalar value head fit leaf states.
- Current read: row count, more epochs, export scalar choice, simple affine calibration, spread leaf sampling, and higher-K exact-state relabeling are not enough. Next pure-leaf work should diagnose model/feature capacity on leaf states or try an unfrozen/larger value model only behind a fit-first gate.
